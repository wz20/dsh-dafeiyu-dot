# 故障恢复

QQ连接等待最多15秒。失败后按2、4、8、16秒逐渐增加间隔，最高30秒重连；配置页显示下一次重连状态，可点击「重新连接」立即核对已保存的网关。

连接后每30秒主动核对QQ登录身份和在线状态，检查完成后才安排下一次。网关失去响应、账号离线和半开连接会退出在线状态并尝试恢复。成功恢复会重置退避状态。登录账号变化时暂停自动重连，保留原绑定，等待用户核对。

重新连接使用已保存的参数，页面中的草稿可继续编辑。网关登录过期需要在本机登录页重新扫码；随后点击重新连接。尚未确认送达的语音、文字与表情不会自动重发。

语音服务不可用时，配置页的连接检查提供实际状态；修复服务、模型或音色后可以重新检查和试听。QQ语音生成失败按现有规则保留文字。挂断、停用、切换模式及卸载会清理对应的采音、合成和连接任务。

记忆整理采用持久队列与有限重试。可在记忆管理中查看待办和失败，修复模型或存储问题后手动重试。写入失败不会把补存标记为成功。
