# 大肥鱼现成清唱

用户确认的歌曲音频通过本机曲库直接返回。每次点播复用已确认文件的原始字节，桌面可播放、重播，QQ按本轮实际歌曲记录发送音频。

## 点播

- “唱个歌”“给我唱首歌”：播放曲库默认歌曲。
- “唱《曲名》”：按曲名或别名选择现成歌曲。
- “现在能唱哪些歌？”：查看可用曲目，保持普通文字回应。

`dafeiyu_sing` 接收可选的 `song` 和 `recordingId`。未指定曲目时省略参数；指定曲目须与曲库匹配。用户点播其他歌曲时，说明当前可用曲目，等用户选择。

## 本机曲库

`$DSH_HOME/dsh-dafeiyu-dot/recorded-songs.json`（默认 `~/.dsh/dsh-dafeiyu-dot/recorded-songs.json`）：

```json
{
  "version": 1,
  "defaultRecordingId": "song-one",
  "recordings": [{
    "id": "song-one",
    "song": "曲名",
    "aliases": ["曲名清唱"],
    "audioFile": "/absolute/path/song.wav",
    "sha256": "已确认文件的SHA-256",
    "approved": true
  }]
}
```

目录由本机管理，模型只能选择曲目。音频的摘要在创建播放记录及重播时校验；变更文件后需重新确认。个人歌曲和目录保存在运行数据中。

每次点播建立独立、绑定当前会话的歌曲记录；本轮真实工具结果负责桌面和QQ音频归属。QQ可发送仅含歌曲、没有附带文字的回复。停用或切换会话模式时按现有取消机制处理。

## 验证

自动验证覆盖默认点播、精确曲名与别名选择、原始音频一致性、文件变更检测、会话隔离、取消、桌面歌曲投影以及QQ音频发送。用户确认的现成音频按原样复用。
