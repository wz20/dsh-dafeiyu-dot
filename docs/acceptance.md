# 验收方法

当前版本增加BreezeBlue官方API的情绪语音接入，保留本地与OpenAI兼容语音、NapCat扫码登录及记忆检索。

## 记忆

自动测试使用14条虚构事实与22个固定问题，覆盖项目、环境、属性、换措辞、正负偏好、时间及无答案场景。该回归集的精确结果集合由6/22提升为22/22；返回结果中的相关项占比由32.9%提升为100%。这些数字只描述该合成回归集，不能代表真实聊天的总体准确率。

额外测试覆盖普通全文备注、历史记录关键词、带符号的实体、未知引号项目、环境词歧义、混合正负和过去/现在的比较。更正、遗忘、隔离、来源捕获与压缩补存沿用既有测试。

手动验收可使用自己愿意保存的一个事实，再换种问法询问；随后明确更正，并确认旧值不会当作当前事实返回。群聊应分别核对不同成员的记忆归属。临时验收文本应明确标注临时用途。

## 故障恢复

自动测试使用临时数据与模拟网关，覆盖连接一直不打开、半开连接、无心跳离线、账号变化、重连退避、晚回包和卸载清理。发送状态不明的消息保持不重发。

手动可在配置中心QQ页点击「重新连接」，确认弹出NapCat扫码窗口；核对二维码、刷新、关闭和手机确认后的自动恢复，确认账号与配对保持。首次保存NapCat管理密钥后应清空密码框。故障测试应避开正在发送的真实消息。

## 公开源码与本机资料

源码、实际安装包和源码归档均应通过发布隐私检查，并保留各自哈希。个人配置、身份、会话、记忆和自定义媒体保存在项目外。运行配置与已确认事实的保留情况由本机验收记录核对。

本版本自动测试和实际原生检查的完成范围见发布校验记录。语音听感、长期运行稳定性及连续多天陪伴体验仍由实际使用验收。

0.11.1：598项自动测试通过，语法检查通过。资源路径按目录包含关系校验，Windows与POSIX路径规则覆盖末尾分隔符、中文目录、混合斜杠、盘符、UNC、绝对路径和越界访问；HTTP测试核对图标、图片、CSS、脚本与本机音效覆盖。GitHub Actions对Windows和Linux持续运行资源回归，Windows 11的DSH界面由反馈用户更新后确认。
