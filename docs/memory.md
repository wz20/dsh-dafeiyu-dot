# 记忆宫殿

长期事实保存为Markdown文件，索引帮助定位人物、主题与日期。回复前按本轮输入检索当前有效事实，最多6条，每条最多480字符，总上下文不超过3600字符；需要细节时可按ID精读。

检索先识别明确的项目、环境、属性和时间要求，再按关键词与别名排序。事实必须有真实用户文字证据，保留来源身份与时间；共同经历也需要用户明确叙述或确认。助手台词、图片补充说明、临时测试、假设、密钥及明确拒绝记录的内容不作为长期事实来源。

当前更正优先，旧记录保留更正关系；遗忘记录受墓碑保护。关闭记忆或回到标准模式后清空后续召回。主人私聊、不同群和不同群成员使用独立存储，归属不明时停止访问。

压缩前将本次范围内已完成轮次的合格来源写入持久队列，再开始摘要。默认最多再等1.5秒整理，剩余待办继续后台处理。队列或来源排除记录写入失败时暂停本次压缩；取消保留已写入的任务。

每次插件接管会话时固定新的观察起点，先验证上次锚点。升级前、停用和离线期间未经本次观察的历史不自动回补，已有事实和持久待办继续恢复。关闭记忆期间只保存来源身份排除哈希；崩溃前尚未入队、也未完成补存的内容仍可能丢失。

宫殿包含`owner/`、`self/`、`索引/`和`.state/`；群成员位于`groups/<group>/members/<member>/`。备份时复制整个目录，包含隐藏状态与遗忘墓碑。索引可以重建；状态损坏时应保留文件并恢复备份。

检索是确定性本地实现，不能替代完整语义理解。验收应包含换措辞、跨实体、正负偏好、历史与当前、更正和遗忘等情况，测试事实使用虚构样例。
